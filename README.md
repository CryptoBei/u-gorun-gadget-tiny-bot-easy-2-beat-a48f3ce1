A tiny long-only bars-replay bot for hourly Solana-ecosystem bars. It buys brief dips only while the short trend still points up, banks small gains quickly, and cuts stale risk with stops and time limits. It uses only the bars the harness sends: no network, no external data, and no real funds.

## Run it

```sh
node main.ts
```

The harness feeds `agent-fun/bars-replay/v1` lines on stdin and reads one reply per batch on stdout.
